# Anjo 360 Tour

Produto próprio da Anjo Digital: editor de tours virtuais 360° com mapa, hotspots e publicação no Google Street View.

## Destaques
- Backend FastAPI + SQLite, visualizador Marzipano
- Google Maps / Places / Street View Publish API
- Proteção contra DNS rebinding (TrustedHost) e testes automatizados
- Código privado; demonstração sob pedido
